## 四、双向互链机制（本轮新增的架构改动）

工具从「孤岛页面」变成与内容互相导流的结构：

```
文章 frontmatter: tool: <工具 slug>
        ↓ build.mjs 建立 toolBySlug 索引
文章页文末 → aside.tool-link 卡片（图标 + 名称 + 描述 + 「去用工具 →」）

tools.json 条目: guide: <文章 slug>
        ↓ build.mjs 建立 postBySlug 索引
工具页顶部 → aside.guide-link（「先看原理，再用工具：<链接>」）
```

**为什么两侧都要写**：只写文章侧，工具页访客看不到阅读入口；只写工具侧，文章访客走不到工具。
两张索引在**构建期**解析而非运行时 fetch —— 链接是静态 HTML，爬虫可直接跟进，且不依赖 JS。

产物侧回填：`_dist/posts.json` 每条新增 `tool` / `toolUrl`，`_dist/tools.json` 每条新增 `guide` / `guideUrl`。
