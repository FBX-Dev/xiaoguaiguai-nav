### 关键实现口径

- **预产期与孕周**：内格勒法则（LMP + 280 天）+ 周期修正（`adjust = cycle - 28`）；列 8 个产检节点并标注「已过 / 当前阶段 / 未到」
- **奶量参考**：按月龄给区间，另按体重算第二组（每公斤每天 120–180 ml）；`spoonsPerFeed = midPer / scoop` 换算勺数
- **识字量**：分层抽样（不是逐字测试），只给区间与选书方向，不评价孩子
- **BMI 与体脂**：BMI 分界 18.5 / 24 / 28，并回算对应区间体重（`lowW = 18.5·m²`、`highW = 23.9·m²`）；体脂用美国海军围度公式（先转英寸）
- **基础代谢**：Mifflin-St Jeor 公式 + 四档活动系数 + 三大营养素分配
- **产假津贴**：`allowance = (avg / 30) × total`，并推算起止日期与返岗日
- **亲戚称呼**：关系链 `MAP` 匹配表（覆盖直系/祖辈/表堂/姻亲/子女配偶/侄甥），未命中回落逐级描述

## 五、「3 的倍数」规则的落地位置（4 处）

规则本身是版式要求，必须落到「生成 → 校验 → 验收」全链路，否则下次扩容会静默失效。

| 位置 | 文件 | 具体改动 |
|---|---|---|
| ① 索引文档 | `tools/tools.json` 的 `_readme` | 写明「每个分类的工具数必须是 3 的倍数（6、9、12…）…各分类不必相同」 |
| ② 生成层 | `build.mjs` | 工具网格从 `repeat(auto-fill, minmax(268px,1fr))` 改为 `repeat(3, minmax(0,1fr))` **固定 3 列** |
| ③ CI 判据 | `.github/workflows/deploy.yml` | 新增 `if [ $((TC % 3)) -ne 0 ]` 硬门禁，不满足直接 fail |
| ④ 本地验收 | `_selfcheck.py` | `MIN_TOOL_PER_CAT` 4 → 6，配额循环新增 `n % 3 != 0` 判据 |

**为什么必须固定 3 列**：`auto-fill + minmax(268px)` 在视口变化时列数会在 2/3 之间漂移；而 3 的倍数在 2 列下反而剩 1 个空位，规则失效。因此改为固定 3 列，并在 860px 断点**只收窄间距**（`gap: 10px`、`a.card { padding: 14px 14px }`）而非降列数；560px 以下仍回落 1 列（1 列时任何数量都整除，无空缺）。

### 版式实测（`/tools/` 页各分类网格）

| 视口 | 列数 | 每类工具 | 末行余数 |
|---|---|---|---|
| 1440px | 3 | 6 | **0** ✅ |
| 900px | 3 | 6 | **0** ✅ |
| 560px | 1 | 6 | **0** ✅ |
| 390px | 1 | 6 | **0** ✅ |

## 七、验收脚本的防复发改造

扩容时发现多个脚本**硬编码了旧数量**（20 / 60 / 12），下次扩容会误报失败。本轮一并改为**从构建产物动态读取**：

| 脚本 | 原硬编码 | 改后 |
|---|---|---|
| `_trash_e2e.cjs` | `items === 60`、`toolCards === 20`、`res.length === 20`、写死的 `ALL_TOOLS` 清单 | 新增 `TOTAL_POSTS` / `TOTAL_TOOLS`（带 `try/catch` 回落），`ALL_TOOLS` 从 `/tools.json` 读取 |
| `_trash_layout.cjs` | `/posts/ 索引条目 = 60`、`分类页 12 篇内容`、写死的 `ALL_TOOLS` 清单 | 新增 `TOTAL_POSTS` / `CAT_POSTS` 动态常量，断言改为与产物比对 |
| `_selfcheck.py` | `MIN_TOOL_PER_CAT = 4` | 改为 `6` 且加 `% 3` 判据 |

> 保留的设计：`BASE` 环境变量不变，无 `_dist` 时动态常量为 0、相关断言自动跳过，因此脚本**仍可用于纯线上巡检**。
