## 一、公开地址格式（已可用）

```
https://xiaoguaiguai.cn/media/<分类拼音>/<序号>-<语义>.<ext>
```

例：`https://xiaoguaiguai.cn/media/yuer/01-growth-curve.webp`

### 为什么是这个格式

规范里有两条硬约束存在冲突，本方案是同时满足两边的解法：

| 约束 | 原文 | 影响 |
|---|---|---|
| ① 配图必须走 R2 | 「cover 只接受 Cloudflare R2 公开URL，图片不上传Git仓库」 | 图片必须在桶 `xiaoguaiguai-media` 里 |
| ② 禁用子域名 | 「首期禁止任何子域名：`xxx.xiaoguaiguai.cn` 全部搁置」 | 不能用 `media.xiaoguaiguai.cn` |

另外 **`r2.dev` 域名在国内被 DNS 污染**（项目铁律 11，实测解析到 Meta 的 IP），绝对不能用。

→ 故用 Worker 绑定主域名子路径 `/media/*` 反代桶。**两条约束同时满足，且国内可正常访问。**

## 二、上传命令（复制即用）

```bash
cd D:/workbuddy/netspace/xiaoguaiguai-nav/media-proxy

# 单张上传（注意必须加 --remote，否则只写本地模拟环境）
npx --yes wrangler@4 r2 object put "xiaoguaiguai-media/yuer/01-growth-curve.webp" \
  --file "本地图片绝对路径.webp" \
  --content-type "image/webp" \
  --remote
```

> ⚠️ **`--remote` 不能省**。不加它 wrangler 只写本地模拟桶，线上永远取不到图。

批量上传可写个循环脚本；命名请严格按上表，便于日后维护。

## 四、配图规格要求

- 比例 **16:9**；建议 800×450 或 1200×675；单张 **≤ 200 KB**（webp / jpg）
- 调性：柔和低饱和、暖色或莫兰迪色系，留白充足，反焦虑、松弛感
- **禁止**：真人儿童面部特写、医疗场景、文字水印、夸张营销元素
- 命名：`{分类拼音}/{序号}-{语义}.{ext}`
