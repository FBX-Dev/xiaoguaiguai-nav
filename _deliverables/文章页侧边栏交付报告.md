## 一、问题与实测数据

文章页正文固定 720px（`.narrow`），而容器内宽 1076px，右侧长期留白。改造前实测：

| 视口 | 容器宽 | 正文宽 | **右侧空白** |
|---|---|---|---|
| 1440px | 1120px | 720px | **378px** |
| 1280px | 1120px | 720px | **378px** |
| 900px | 900px | 720px | 158px |
| 768px | 768px | 720px | 26px |

378px 足够容纳一个 288px 侧栏 + 36px 间距，**且正文一行都不用改**。
正文宽度必须保持 720px：中文最佳行长约 38 字/行，收窄到 640 会挤、放宽到 900 会掉行，
用「压正文换侧栏」等于牺牲阅读体验去填空白，得不偿失。

## 二、侧栏三块内容（含设计取舍）

| 位置 | 模块 | 数据来源 | 为什么放它 |
|---|---|---|---|
| 上 | 方形广告位 | `data/sidebar.json` → `ad` | 变现入口置顶，位置固定才好按位报价 |
| 中 | 本分类工具 | `tools.json` 按分类自动取 | 用户指定核心功能；与文末「配套工具」不重复——文末那 1 个是本文专属，这里列的是该分类全景 |
| 下 | 本页目录 | 正文 h2 自动抓取 | 文章平均 1643 字、h2 有 4~8 个，长文有跳转刚需 |

**刻意不放「相关阅读」**：页面底部已有「同类内容」区块（3 篇），再放一次会让同一屏出现两组相似链接，反而稀释点击率。

**目录自动隐藏**：h2 少于 3 个时不渲染——两个标题点一下不如直接滑两屏，目录反成干扰。

## 三、响应式断点（依据容器内宽 = 视口 − 44px 内边距）

| 视口 | 布局 | 正文 | 侧栏 |
|---|---|---|---|
| ≥1121px | 两栏 | 720px | 288px sticky |
| 1033~1120px | 两栏 | 720px | 240px sticky（收窄保正文） |
| ≤1032px | 单栏 | 720px | 移到正文之后，横排三卡 |
| ≤640px | 单栏 | 自适应 | 侧栏内单列 |

**sticky 的两个细节**：
1. `top: 77px` = 站头 61px + 16px 呼吸位，否则吸顶时被站头压住
2. `max-height: calc(100vh - 97px)` + 内部滚动 —— 三卡实测总高约 1093px，比常见视口（900px）高，不限高会「卡住但底部看不全」，广告位反而滚出视野

**锚点偏移**：带 id 的 h2 设 `scroll-margin-top: 80px`，跳转后标题落在站头下方而非被遮住。

## 四、后台配置模块

后台新增 singleton「**侧边栏与广告位**」（内容库侧栏直接可见，点开即编辑），
编辑 `data/sidebar.json`，保存后 1~2 分钟自动构建上线。

| 字段 | 类型 | 说明 |
|---|---|---|
| 显示广告位 | 开关 | 关掉后整卡不渲染，其余两项自动上移 |
| 角标文案 | 文本 | 默认「广告」，合规起见建议保留 |
| 广告图片地址 | 文本 | 默认 `/assets/sidebar-ad.webp`（站内方形品牌图） |
| 点击跳转地址 | 文本 | 留空则图片不可点 |
| 图片说明文字 | 文本 | alt，兼作加载失败时的替代文字 |
| 广告代码 | 长文本 | **填写后覆盖图片**，用于粘贴 AdSense 等第三方代码 |
| 显示本分类工具 / 模块标题 | 开关 + 文本 | 工具列表自动生成，无需手工维护 |
| 显示本页目录 / 模块标题 | 开关 + 文本 | 自动抓取正文二级标题 |

### 容错（已实测）
- JSON 语法错误 → 打日志 + 回落内置默认值，构建继续
- 字段类型不对（如 `ad` 写成字符串）→ 逐字段回落默认值
- 文件缺失 → 整体回落默认值

三种异常下构建均成功，**后台写坏一个字段不会导致整站发布失败**。

### ⚠️ 贴外部广告前必读
`_headers` 现有 CSP 会拦死 AdSense。文件内已写好完整改造说明（需放行
`pagead2.googlesyndication.com`、`googleads.g.doubleclick.net` 等，且 `script-src` 需含 `'unsafe-inline'`）。
默认站内图片走 `/assets/*`，不受 CSP 影响，可直接用。

## 七、顺手修掉的两个隐患

1. **CMS 缩进错误**：首次编辑 `admin/config.yml` 时吞掉一个换行，导致注释与 `- name: posts` 挤在同一行，YAML 解析失败。已修复并用 `yaml.safe_load` 校验通过。
2. **CI 广告卡判据失效**：`grep -q 'class="sb-ad"'` 是精确子串匹配，而实际 HTML 是 `class="sb-card sb-ad"`，**永远匹配不到、会误报失败**。已改为 `grep -qE 'class="[^"]*sb-ad'`。这个 bug 若没在本地实跑 CI 逻辑，会在推送后才暴露。
